                                                                                          A. Informasi NIM

                                                                                          Deskripsi

                                                                                          Program membaca satu baris NIM, memvalidasi panjangnya, lalu menampilkan informasi program studi, angkatan, dan nomor urut.

                                                                                          Format NIM

                                                                                          NIM terdiri dari tepat 8 karakter dengan struktur:

                                                                                          Contoh: 11S18005

                                                                                          • Prefix 11S → Sarjana Informatika

                                                                                          • Digit 18 → angkatan 2018

                                                                                          • Digit 005 → urutan 5

                                                                                          Tabel Prefix Program Studi

                                                                                          Jika prefix tidak cocok dengan tabel di atas, tampilkan pesan Kode tidak tersedia dan program berhenti.

                                                                                          Alur Program

                                                                                          1. Baca NIM dari input.

                                                                                          2. Jika panjang NIM bukan 8, cetak pesan error dan program berhenti.

                                                                                          3. Ambil 3 karakter pertama sebagai prefix, cocokkan dengan tabel program studi.

                                                                                          4. Jika prefix tidak ada di tabel, cetak Kode tidak tersedia dan program berhenti.

                                                                                          5. Ambil karakter indeks 3–4, gabungkan dengan "20" di depan, konversi ke bilangan bulat sebagai angkatan.

                                                                                          6. Ambil karakter indeks 5–7, konversi ke bilangan bulat sebagai urutan.

                                                                                          7. Tampilkan informasi lengkap.

                                                                                          Contoh Input Valid

                                                                                          Input:

                                                                                          B. Perolehan Nilai

                                                                                          Deskripsi

                                                                                          Program menghitung perolehan nilai akhir mahasiswa berdasarkan bobot komponen penilaian dan data perolehan tiap komponen, lalu mengkonversi ke grade.

                                                                                          Format Input

                                                                                          Baris 1–6: Bobot masing-masing komponen (bilangan bulat)

                                                                                          xxxxxxxxxx

                                                                                          5

                                                                                          Ketentuan: Jumlah keenam bobot harus tepat 100. Jika tidak, program mencetak error dan berhenti.

                                                                                          Baris 7 dst: Data komponen penilaian, satu per baris, format:

                                                                                          xxxxxxxxxx
                                                                                          1
                                                                                          1
                                                                                          Simbol|Bobot|Perolehan-Nilai

                                                                                          Baris terakhir: --- (menandakan akhir input komponen)

                                                                                          Tabel Simbol Komponen

                                                                                          Validasi Data Komponen

                                                                                          Spasi di sekitar field boleh ada dan diabaikan (trim).

                                                                                          Rumus Perhitungan

                                                                                          Untuk setiap simbol:

                                                                                          1. Akumulasi total bobot komponen (totalPA, totalT, dst.)

                                                                                          2. Akumulasi perolehan yang sudah di-clamp

                                                                                          3. Hitung persentase perolehan per komponen (skala 100):

                                                                                            xxxxxxxxxx
                                                                                            1
                                                                                            1
                                                                                            perolehanX100 = (perolehanX / totalX) * 100   // integer, jika totalX = 0 maka 0

                                                                                          4. Hitung kontribusi ke nilai akhir:

                                                                                            xxxxxxxxxx
                                                                                            1
                                                                                            1
                                                                                            kontribusiX = (perolehanX100 / 100) * bobotX

                                                                                          5. Nilai akhir = jumlah semua kontribusi

                                                                                          Satu simbol boleh muncul lebih dari sekali; bobot dan perolehannya dijumlahkan.

                                                                                          C. Perbedaan L dan Kebalikannya

                                                                                          Deskripsi

                                                                                          Diberikan matriks persegi (baris = kolom). Program menghitung:

                                                                                          • Nilai L — jumlah elemen membentuk huruf L

                                                                                          • Nilai Kebalikan L — jumlah elemen membentuk L terbalik (cermin horizontal)

                                                                                          • Nilai Tengah — elemen tengah matriks

                                                                                          • Perbedaan — selisih absolut Nilai L dan Nilai Kebalikan L

                                                                                          • Dominan — nilai dominan berdasarkan aturan khusus

                                                                                          Format Input

                                                                                          Baris 1: Ukuran matriks N (bilangan bulat)

                                                                                          Baris 2 s/d N+1: N bilangan bulat per baris, dipisahkan spasi

                                                                                          Pola Nilai L (matriks ≥ 3×3)

                                                                                          Elemen yang dijumlahkan untuk Nilai L:

                                                                                          1. Seluruh kolom pertama (indeks kolom 0)

                                                                                          2. Seluruh baris terakhir kecuali sel pojok kanan bawah

                                                                                          xxxxxxxxxx
                                                                                          8
                                                                                          1
                                                                                          Contoh matriks 3×3:
                                                                                          2
                                                                                          

                                                                                          3
                                                                                          [1] [2] [3]
                                                                                          4
                                                                                          [4] [5] [6]
                                                                                          5
                                                                                          [7] [8] [9]
                                                                                          6
                                                                                          

                                                                                          7
                                                                                          Nilai L = 1 + 4 + 7 + 8 = 20
                                                                                          8
                                                                                                   ↑kolom↑  ↑baris terakhir (tanpa 9)↑

                                                                                          Pola Nilai Kebalikan L (matriks ≥ 3×3)

                                                                                          Elemen yang dijumlahkan untuk Nilai Kebalikan L:

                                                                                          1. Seluruh kolom terakhir (indeks kolom N-1)

                                                                                          2. Seluruh baris pertama kecuali sel pojok kiri atas

                                                                                          xxxxxxxxxx
                                                                                          2
                                                                                          1
                                                                                          Nilai Kebalikan L = 3 + 6 + 9 + 2 = 20
                                                                                          2
                                                                                                              ↑kolom↑  ↑baris pertama (tanpa 1)↑

                                                                                          Nilai Tengah

                                                                                          Aturan Dominan

                                                                                          xxxxxxxxxx

                                                                                          jika perbedaan == 0  → dominan = nilaiTengah
                                                                                          2

                                                                                          E. Jam Saya

                                                                                          Deskripsi

                                                                                          Program membaca jam awal berformat HH:MM, lalu menggeser menit sesuai perintah +N atau -N sampai baris ---. Program menampilkan jam akhir, total menit geser, dan berapa kali pergantian hari (melewati tengah malam).

                                                                                          Perhitungan memakai aritmetika menit dan modulo 24 jam (1440 menit). Tidak boleh memakai Date, Calendar, atau LocalTime.

                                                                                          Format Input

                                                                                          Baris 1: Jam awal HH:MM

                                                                                          Baris berikutnya: Perintah geser, satu per baris

                                                                                          Validasi Jam Awal

                                                                                          Jam dianggap valid jika:

                                                                                          1. Tepat 2 bagian dipisah :

                                                                                          2. Jam dan menit berupa bilangan bulat

                                                                                          3. Jam berada di rentang 0–23

                                                                                          4. Menit berada di rentang 0–59

                                                                                          Digit jam tidak harus 2 karakter (8:30 diterima dan dicetak sebagai 08:30).

                                                                                          Jika jam tidak valid, cetak Jam tidak valid dan program berhenti.

                                                                                          Validasi Perintah

                                                                                          Aturan Perhitungan

                                                                                          1. Ubah jam awal menjadi total menit: jam * 60 + menit.

                                                                                          2. Setiap perintah menambahkan atau mengurangi menit.

                                                                                          3. Normalisasi ke rentang 0–1439:

                                                                                            • Jika ≥ 1440, kurangi 1440 dan tambah Pergantian Hari

                                                                                            • Jika < 0, tambah 1440 dan tambah Pergantian Hari

                                                                                          4. Setiap kali melewati batas 24 jam (maju atau mundur) dihitung 1 pergantian hari.

                                                                                          5. Format keluaran jam memakai 2 digit (%02d).

                                                                                          6. Total Menit menampilkan tanda + hanya jika hasilnya positif. Nol dicetak 0. Negatif tetap memakai tanda -.
